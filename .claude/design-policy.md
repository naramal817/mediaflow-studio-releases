## 한글 조판 — 라틴 습관 그대로 들고 오지 않는다

- 한글엔 대소문자가 없다 — 대문자 eyebrow에 `letter-spacing` 금지(받침 붙음)
- 한글 굵기는 Regular↔Bold 2단만 실질적으로 쓴다(라틴 300–700 사다리 흉내내지 않는다) —
  부족한 위계는 색·크기·박스로 채운다
- `word-break: keep-all`(어절단위 줄바꿈), `break-all` 금지
- 본문 `line-height: 1.7`(실측 1.68–1.80), 단행 요소는 1.2–1.4
- 국문 증시 관습: **빨강=상승·파랑=하락**(영문 관습 green=up/red=down과 반대 — 증감을 색으로
  인코딩할 땐 반드시 확인)

## 공통 규칙(전사 규약과 중복, 여기서 한 번 더 — UI 작업 시 바로 보이게)

- 간격은 4px 스케일만(4·8·12·16·20·24·28·32)
- 폰트는 Pretendard **static** CDN(variable 버전은 크롬 폴백 버그)
- 이모지 UI 금지(문서·커밋메시지는 무관), `--faint` 본문 금지(안 보임)
- 표 = 검색+구분필터+정렬+헤더고정 4종 필수, 상세는 우측 드로어(중앙모달 혼용 금지)
- 반응형 검증 2종: PC는 16:9 비율, 모바일은 작업 시점 최신 아이폰·갤럭시 플래그십 실뷰포트

## 시맨틱 상태 색 토큰 — 기본값(브랜드 미정 프로젝트용)

각 프로젝트가 자기 브랜드 색을 아직 못 정했을 때 상태 배지(성공/경고/위험/중립)에 쓸 **기본
토큰**이다. 브랜드 톤이 정해진 프로젝트는 이 값을 그대로 안 써도 된다 — 단 "따뜻한 회색 계열
중성색을 고른다"는 원칙(§2 PRINCIPLES.md)은 유지한다. 아래 값은 squaredot에서 이미 실사용
중이던 값을 그대로 정본화한 것이다(새로 발명하지 않음 — 이미 있는 걸 흩어지지 않게 모은 것,
규약 28항).

```css
:root {
  --status-success: #059669;   /* 성공/게재확인/완료 등 */
  --status-success-bg: rgba(5, 150, 105, .12);
  --status-warning: #b45309;   /* 주의/유사·불확실 */
  --status-warning-bg: rgba(180, 83, 9, .12);
  --status-danger: #dc2626;    /* 실패/거부/삭제 */
  --status-danger-bg: rgba(220, 38, 38, .12);
  --status-neutral: #64748b;   /* 미확인/해당없음 */
  --status-neutral-bg: rgba(100, 116, 139, .12);
  --status-muted: #94a3b8;     /* 비활성/희미(faint 아님 — 이건 배지 전용) */
  --status-muted-bg: rgba(148, 163, 184, .1);
}
```

새 프로젝트에서 상태 배지 색이 필요하면 이 토큰을 먼저 쓴다 — 색을 새로 지어내지 않는다
(규약 11항: 하드코딩 금지, 기존 자산 먼저 찾기).

## 검토 3단계

① 자가검사(요청 프로젝트 직접, 통과해야 접수) → ② 기계검토(겹침·넘침·정렬·색·글꼴) →
③ 사람판단(디자인실장 — 위계·톤·업종적합성·브랜드). 판정은 통과/조건부통과/반려 셋뿐(점수 없음).
