**`chain.json` 신설(19단계, 2.11.2→2.19.6) — 이제 2단계 이상 뒤처진 설치본도
"지금 확인" 한 번으로 따라잡습니다.** 그동안 `latest.json`은 "지금
최신이 뭐냐"와 그 직전 버전에서 온 patch 하나만 갖고 있어서, 두 단계 이상
뒤처지면 patch를 받아놓고도 전제 버전이 안 맞아 거부됐습니다(설치본이
2.18.1인데 2.19.2용 패치를 받는 식). `chain.json`은 이 채널이 지금까지
게시해 온 patch 전부를 순서대로 이어 놓은 색인이라, 설치본이 아무리
뒤처져 있어도 그 사슬을 따라 여러 patch를 한 번에 순서대로 적용합니다
(소스 CONTRACT 145). **단, 이 능력은 2.19.6부터 포함됩니다** — 2.19.5
이하 설치본은 이번 한 번만 전체 설치본으로 갱신해야 하고, 그 이후부터는
몇 단계를 건너뛰어도 자동 업데이트가 항상 작동합니다.

앱의 "지금 확인"은 **2.16.1 설치본**에서 그대로 적용됩니다. 패치의 이전 해시는 git(LF)이 아니라 **설치된 파일(CRLF, 코덱스 2.16.x 패치가 쓴 그대로)** 기준으로 맞췄습니다 — 이후 패치도 같은 기준으로 만들어야 합니다(소스 CONTRACT 91). 2.14.1 이하에서는 패치 기준 파일이
달라 적용이 거부되므로 전체 설치본으로 덮어 설치하십시오.

2.17.0 전체 설치본(`MediaFlow-Studio-Setup-Windows-2.17.0.bat` · Mac `.zip` · `mediaflow-studio-2.17.0.zip`)은
리눅스 세션에서 만들어 오너에게 대화로 직접 전달했습니다. **Windows GUI 설치기 `.exe` 와 트레이
런처 `MediaFlow Studio.exe` 는 `csc.exe` 가 있는 Windows PC 에서만 만들어지므로 이번엔 없습니다** —
`.bat` 설치본은 기존 트레이 exe 를 그대로 둡니다. GitHub Release 첨부는 그 exe 가 만들어진 뒤
관제탑이 올립니다(소스 CONTRACT 91).

2.17.0 에 들어간 것: 내보내기 오버레이·자막 위치를 편집기 미리보기와 일치(CONTRACT 87) · 부분 서식(88) ·
